# Решение кейса «Мини-игра для получения промокодов» (Платформа «Я в Агро»)

Проект разработан в рамках стипендиальной программы Россельхозбанка (направление **«Информационные технологии»**, продукт **«Я в Агро»**).

---

## 🎯 1. Описание задачи и концепция

### Постановка задачи:
Создать короткую мини-игру для студентов:
- Один игровой сеанс занимает не более **1 минуты**;
- Завершается гарантированной наградой (промокодом);
- Формирует интерес к экосистеме банка и реальным агро-партнёрам;
- Сценарий: запуск $\rightarrow$ 1–2 игровых действия $\rightarrow$ экран с промокодом $\rightarrow$ копирование кода и переход к партнёру.

### Выбранная механика:
**«Агро-Колесо Фортуны» (Wheel of Fortune)** на HTML5 Canvas с плавной физикой вращения (Ease-Out кубическая интерполяция), конфетти-эффектом и адаптивным интерфейсом под мобильные устройства и десктоп.

---

## 🌾 2. Партнёры и промокоды

В игре участвуют бренды экосистемы Россельхозбанка и партнёрские сервисы:
1. **Своё Родное** (`RODNOE-20-AGRO`) — скидка 20% на заказ фермерских продуктов и сыров.
2. **Ростсельмаш Shop** (`RSM-STUDENT-15`) — скидка 15% на официальный мерч и сувениры.
3. **Я в Агро Лекторий** (`AGRO-BOOKS-FREE`) — 1 месяц бесплатного доступа к образовательным агро-курсам.
4. **Своё за городом** (`ZAGOROD-TRAVEL-25`) — скидка 25% на эко-туры и загородные путешествия.
5. **Coffee & Agro Hub** (`COFFEE-AGRO-CAMPUS`) — кофе в подарок в студенческих кампусах.
6. **Своё Родное (Подарочный)** (`FARM-BOX-500`) — сертификат на 500 ₽ на фермерские корзины.

---

## 📱 3. Структура экранов (в соответствии с ТЗ)

1. **Экран запуска (Onboarding)**:
   - Приветственный баннер с ценностью для студента;
   - Быстрые правила игры за 3 шага;
   - Кнопка «Начать игру» с эффектом свечения.
2. **Игровой экран (Gameplay)**:
   - Интерактивное колесо фортуны (HTML5 Canvas с сегментами призов и стрелкой);
   - Кнопка «Крутить колесо! 🎯»;
   - Плавная анимация вращения (4 секунды) с точной остановкой на выпавшем секторе.
3. **Экран награды (Reward)**:
   - Вспышка праздничного конфетти (`canvas-confetti`);
   - Карточка выигранного приза и подробные условия;
   - Поле с промокодом и кнопка **«Скопировать»** (с уведомлением в буфер обмена);
   - Кнопка **«Перейти к партнёру»** (открытие сайта партнёра в новой вкладке);
   - Возможность сыграть ещё раз («Крутить ещё раз»).

---

## 🛠️ 4. Стек технологий и архитектура

- **HTML5 & CSS3**: Адаптивный мобильно-ориентированный интерфейс (Mobile-First), Glassmorphism, CSS-переменные, анимации.
- **JavaScript (Vanilla ES6+)**:
  - Высокопроизводительный рендеринг колеса через `<canvas>`;
  - Математически точный расчет попадания сектора под верхний указатель;
  - Clipboard API для быстрого копирования промокода;
  - Zero-dependency (единственная внешняя библиотека — легковесный конфетти CDN для вау-эффекта).
- **Интеграция**: Приложение готово к встраиванию в Telegram Web App (TMA), мобильное приложение через WebView или на сайт через `<iframe>`.

---

## 🚀 5. Как запустить

Проект полностью автономен и не требует сборщиков:
1. Откройте файл `index.html` в любом современном браузере (Chrome, Edge, Safari, Firefox).
2. Или запустите локальный сервер:
   ```bash
   python -m http.server 8080
   ```
   и перейдите по адресу `http://localhost:8080`.
